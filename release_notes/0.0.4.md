# Sky Scribble Jump 0.0.4

Launcher gameplay and platform polish release.

## Highlights

- Added an imagegen-generated doodle launcher cannon prop.
- Added launcher gameplay: the player enters the barrel, shrinks into it, waits through a visible charge-up squeeze, then fires upward like a projectile.
- Tuned the launcher to be smaller, sit on the platform more naturally, and use a longer charge-up timing.
- Reworked Game Over retry behavior so only the `Try Again` button restarts the game, with a pressed-button animation.
- Regenerated the blue moving platform with the same `128x40` thickness as the other platforms while restoring its hand-drawn surface details and side motion marks.
- Slightly increased normal platform jump height for a livelier bounce.
