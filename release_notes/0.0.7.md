# Sky Scribble Jump 0.0.7

Godot project structure and open-source readiness release.

## Highlights

- Refactored the single-script prototype into modular Godot scenes and scripts.
- Moved player behavior into `Player.tscn` / `Player.gd`.
- Moved platform behavior into `JumpPlatform.tscn` / `JumpPlatform.gd`.
- Added `PlatformSpawner.gd` for platform generation, movement updates, and cleanup.
- Added `LauncherSequence.gd` for launcher entry, charge, and firing flow.
- Moved persistent UI node structure into `GameHUD.tscn`, `StartScreen.tscn`, and `GameOverScreen.tscn`.
- Added `GameTuning.gd` and `resources/game_tuning.tres` so core gameplay values can be edited in the Godot inspector.
- Added an MIT `LICENSE`.
- Added `docs/TESTING.md` with gameplay, export, and visual regression checklists.
- Updated contributor and open-source documentation to match the new structure.
