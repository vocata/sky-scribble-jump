# Sky Scribble Jump 0.0.1

Initial playable release.

## Highlights

- Added a Godot 4 vertical jumper game inspired by Doodle Jump-style play.
- Added generated bitmap assets for the player, platforms, spring booster, sparkle effects, and notebook background.
- Added normal, moving, fragile, and spring-assisted platforms.
- Added automatic jumping, screen-edge wrapping, camera follow, score tracking, best score, pause, and restart flow.
- Added spring contact behavior: the spring compresses when stepped on, then restores while launching the player higher.
- Added logarithmic long-press horizontal acceleration for more expressive movement.
- Added `Makefile` commands for running, editing, importing assets, and checking the project.

## Run

```bash
make run
```

## Verify

```bash
make check
```
