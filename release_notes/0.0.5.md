# Sky Scribble Jump 0.0.5

Start screen and macOS export release.

## Highlights

- Added a dedicated doodle-style start screen so the game waits for the player to click `Start` before beginning.
- Added imagegen-generated start screen and start button assets matching the existing notebook / sticker visual style.
- Regenerated the start screen at `1024x1536` to match the main game and Game Over backgrounds.
- Added a macOS export preset for Godot.
- Added `make export-macos` to build a macOS app zip.
- Reworked macOS packaging to re-zip the exported `.app` with `ditto`, making the archive friendlier to Finder and Archive Utility.
- Ignored local `build/` output so generated app packages do not get committed.

## Verify

```bash
make check
make export-macos
```
