# Sky Scribble Jump 0.0.3

Game Over screen polish release.

## Highlights

- Added a dedicated doodle-style Game Over screen using imagegen-generated artwork.
- Added handmade sticker panel and retry button assets for a more consistent visual style.
- Reworked Game Over copy to be shorter and friendlier: `Oops!`, `Score`, `Best`, and `Try Again`.
- Fixed generated background and UI sticker scaling so large image assets render fully instead of showing cropped top-left portions.
- Kept retry behavior via the button, page click, and `R` key.
