# Sky Scribble Jump 0.0.6

Open-source project cleanup release.

## Highlights

- Reorganized runtime artwork into `assets/art/` with role-based folders for backgrounds, characters, effects, platforms, props, screens, and UI.
- Renamed runtime assets to stable lowercase `snake_case` names without version suffixes.
- Removed unused source, transparent-intermediate, and duplicate generated assets from the repository.
- Updated all Godot script, project icon, and macOS export references to the new asset paths.
- Added contributor-facing documentation with asset naming rules and an open-source publishing checklist.
- Added `.editorconfig` and `.gitattributes` for cleaner cross-machine collaboration.
- Expanded `.gitignore` to keep Godot caches, local builds, apps, and macOS metadata out of commits.
- Updated Makefile defaults to use `godot` from PATH and added `make clean`.

## Verify

```bash
make import
make check
make export-macos
unzip -t build/SkyScribbleJump.zip
```
