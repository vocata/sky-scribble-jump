# Sky Scribble Jump 0.0.2

Visual style and asset cleanup release.

## Highlights

- Reworked the game art into a stronger handmade doodle / sticker / marker style.
- Replaced the background, player, platforms, spring, and sparkle assets with the new doodle set.
- Rebuilt the blue moving platform from the selected source art while preserving its motion wave and arrow decorations.
- Rebuilt the red fragile platform from the selected cracked source art while keeping platform body thickness aligned with the green platform.
- Cleaned generated asset names so current resources use stable names without version suffixes.
- Removed old intermediate `*_v2`, `*_v3`, `*_v4`, and `doodle_v*` resource files.
- Tuned spring placement constants for the new spring asset.
