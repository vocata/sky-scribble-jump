# Sky Scribble Jump 0.0.8

Fire boots boost release.

## Highlights

- Added a fire boots pickup that can appear on non-fragile platforms.
- Added a timed vertical jet boost when the player collects fire boots.
- Added image-generated fire boots pickup art and two matching player-with-fire-boots flame frames.
- Recropped fire boots player frames from the original generated sheet so the character stays centered and the flame animation does not jitter.
- Increased the fire boots jet duration to make the boost feel more substantial.
- Updated gameplay, asset, and README documentation for the new fire boots power-up.
