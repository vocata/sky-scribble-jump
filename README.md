# Sky Scribble Jump

A small Godot 4 vertical jumper inspired by the feel of Doodle Jump, with original art and gameplay.

## Run

Open this folder in Godot 4.6+ and press Play, or run:

```bash
godot --path /Users/leixueyue/Programs/doodle_jump
```

## Controls

- `A` / `Left`: move left
- `D` / `Right`: move right
- `R`: restart after game over
- `P`: pause

The player auto-jumps when landing on platforms. Wrap through the left or right edge to cross the screen.
